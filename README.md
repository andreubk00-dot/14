# Тихий район

Атмосферная одиночная браузерная игра: исследуй заброшенный район, собирай ресурсы, создавай снаряжение и превращай ремонтную станцию в свой дом.

## Запуск

### Без установки

Скачай `releases/quiet-district-one-file.zip`, извлеки единственный HTML-файл и открой его в браузере. Node.js, сервер и интернет для игры не нужны. Все модели, текстуры, звуки и музыка встроены в файл. Можно также открыть размещённый HTML по браузерной ссылке.

### Разработка

Требуется Node.js 22.12+ (в облачной среде используется Node.js 24).

```sh
cd /workspace/14
npm ci --cache /workspace/.cache/npm
npm run dev -- --port 5173
```

Открыть адрес, который напечатает Vite. Нужен браузер с WebGL 2 и аппаратным ускорением. Все модели и текстуры входят в репозиторий; во время игры не нужны сторонние CDN, аккаунты, API-ключи или сервер базы данных.

```sh
npm test         # правила крафта, добычи, сохранения и развития
npm run test:e2e # полноценные браузерные сценарии
npm run build   # production-сборка в dist/
npm run build:standalone # автономный HTML в releases/quiet-district.html
npm run preview # локальная проверка production-сборки
npm start       # production-сборка через сервер Node.js, порт 8080
```

Браузерные тесты используют системный Chromium `/usr/bin/chromium`. Для другого пути: `CHROMIUM_PATH=/path/to/chromium npm run test:e2e`.

## Что реализовано

- Изометрический 3D-район: ремонтная станция, старый квартал, депо, причал водонапорная башня и заброшенный сад.
- Свет сумерек, мягкие тени, туман, свечение фонарей, частицы, вода с анимированными бликами, мокрый асфальт.
- Передвижение клавиатурой, кликом по земле с A*-маршрутизацией, экранным джойстиком на сенсорных устройствах.
- 107 точек добычи с разными материалами и требованиями к инструментам.
- Рюкзак с весом, постоянный склад, повторное появление ресурсов после времени активной игры.
- 58 рецептов: инструменты, оружие, защита, рюкзаки, ботинки, расходники, мебель, восстановление оборудования.
- Новый персонаж KayKit Rogue Hooded (CC0): ходьба, бег, сбор, атаки, использование предметов. Геометрия и текстура сохранены, оставлены 10 нужных анимаций вместо 75.
- HUD с едиными SVG-иконками, явными подписями здоровья и выносливости, загрузкой рюкзака, прогрессом проекта и быстрыми действиями. Неизменившиеся элементы HUD сохраняются в DOM.
- Поиск рецептов, фильтр доступных, статусы требований, маршрут к станции, сохранение прокрутки окна и собственные окна подтверждения.
- Пять повторяющихся заказов соседей: обмен материалов на домашние запасы, условия открытия и время ожидания.
- После восстановления радиостанции: запуск водоснабжения и установка солнечных панелей. Очистка воды и переработка лома добавляют производственные цепочки.
- Ближний и дальний бой с охранными дронами, броня, заряды, аптечки, восстановление здоровья.
- Потерянную при поражении добычу можно вернуть; убежище и экипировка сохраняются.
- Свободное размещение мебели во дворе и открытом интерьере, поворот и перестановка без повторной оплаты.
- Грядки дают урожай, кровати восстанавливают здоровье, фонари освещают дом.
- Рыбалка: ожидание поклёвки, подсечка, три удачных подтягивания, четыре вида находок, коллекция в дневнике.
- Три сюжетных проекта: генератор, мост, радиостанция. Восстановленные объекты сохраняют состояние.
- Автосохранение в localStorage, экспорт/импорт JSON, управление звуком и качеством графики.
- Синтезированные звуки ветра, шагов, воды, инструментов и птиц запускаются после действия пользователя.

## Управление

| Действие | Управление |
| --- | --- |
| Движение | WASD / стрелки / клик по земле |
| Бег | Shift |
| Сбор, станция, отдых, рыбалка | E |
| Атака / подсечка / подтягивание | Пробел |
| Аптечка | Q |
| Станция / рюкзак / обустройство | C / I / B |
| Карта / дневник | M / J |
| Маршрут домой | H |
| Повернуть предмет / ослабить леску | R |
| Выбрать другое действие рядом | F / кнопка со стрелкой |
| Отменить / закрыть | Esc |
| Масштаб | Колесо мыши |

На телефоне доступны экранный джойстик, кнопки атаки и взаимодействия, а также вся панель меню. В меню и при скрытой вкладке игровой прогресс времени приостанавливается. Ресурсы и урожай восстанавливаются только во время активной игры.

## Первый вечер

1. Собери металлолом справа от убежища и доски у ограды.
2. Отнеси добычу к домашним ящикам (`E`) или сложи её через рюкзак, находясь дома.
3. В старом квартале найди электрощит и разобранную технику — это источник проводов и деталей.
4. Подойди к верстаку внутри убежища и открой станцию (`E` или `C`).
5. Во вкладке «Убежище» восстанови генератор: металл 10, провод 4, детали 3.
6. Изготовь удочку, открой карту и отправляйся к причалу.
7. Восстанови мост, исследуй депо и собери радиостанцию.

## Статус и границы первой главы

Это самостоятельная играбельная версия 0.15, а не законченный коммерческий релиз. После радиосигнала доступны вода, заказы и производство. Садовница Лада собирает выбранное производство на склад; доступен заброшенный сад с семенами и питомник. Собака, транспорт и переходы между отдельными картами пока не реализованы. Монетизация, SDK площадок и облачные сохранения не подключены. Сетевого кооператива нет. Баланс и удобство на физических мобильных устройствах требуют дальнейшего пользовательского тестирования.

Оружие оформлено как импульсное оборудование против старых охранных дронов. Рыбалка и выращивание трав позволяют заниматься мирным развитием.

## Ассеты и лицензии

Бесплатные 3D-модели Kenney и KayKit / Kay Lousberg (CC0) скачаны из репозиториев авторов. Разрешено коммерческое использование. Источники, точные коммиты и лицензии: [public/assets/CREDITS.md](public/assets/CREDITS.md).

Архитектура, предметы обустройства, интерфейс, эффекты и синтез звука созданы в проекте. Никакие секреты не нужны и не сохраняются.

## Структура

- `src/game.js` — правила и проверка сохранений без зависимости от графики.
- `src/world.js` — Three.js, район, освещение, модели, геометрия и маршрутизация.
- `src/main.js` — взаимодействие, вылазки, бой, строительство и рыбалка.
- `src/ui.js`, `src/style.css` — интерфейс и адаптация под экран.
- `src/audio.js` — локальный синтез аудио.
- `tests/` — проверки логики и браузерные сценарии.

Ходьба ускорена с 3.1 до 4.1 м/с. Открытые меню не перерисовывают неподвижную 3D-сцену; изменение оборудования, освещения или размера окна обновляет кадр. Она собирает выбранный тип производства на склад, переработчик расходует только складской металл. В меню и вне игры производство приостановлено. Новые семена из заброшенного сада используются для питомника редких трав и заказа соседей.

## Обновление 0.5

Инвентарь использует ячейки со стопками ресурсов, расходниками и ненадетым снаряжением. Четыре слота экипировки находятся рядом: оружие, броня, рюкзак и ботинки. Выбор предмета открывает описание и подходящие действия. Снятые вещи возвращаются в ячейки; снять или заменить рюкзак на меньший можно только после разгрузки. Пустой слот оружия означает бой без оружия.

Склад открывается отдельно у хранилища в убежище. Можно сдать добычу или забрать выбранную стопку целиком либо по единице. Перенос проверяет вес до изменения запасов. Настройка хотбара остаётся во вкладке инвентаря.

Убежище и четыре здания района получили полноценные скатные крыши. При входе крыши и стены плавно становятся прозрачными, при выходе восстанавливаются. Крыши объединены в два меша на здание; изменяемые поверхности исключены из статического объединения геометрии. Проходы и коллизии сохранены.

Предметы используют оригинальные цветные SVG-миниатюры с материалами, светлыми гранями и тенями. Они встроены в игру и не требуют внешних загрузок.


## Обновление 0.6

Стены зданий и их коллизии создаются по одним размерам. Убежище имеет полный наружный контур с передним и боковым входами; ограда оставляет свободную калитку. Торцы скатных крыш закрыты фронтонами, солнечные панели повторяют наклон крыши. Домашний светильник закреплён на стене. Деревья, кусты и трава больше не генерируются внутри зданий.

Коллизии повёрнутых автомобилей соответствуют их ориентации. После ремонта канаву можно пересечь по настилу моста; соседние участки остаются препятствиями. Стационарная мебель и поставленные предметы имеют реальные препятствия для движения, ковёр остаётся проходимым.

При обустройстве учитываются размер предмета, поворот, границы участка, стены, другая мебель и свободные подходы к входам и взаимодействиям. Предпросмотр и установка используют одну проверку. Мебель ставится на высоту пола дома или земли во дворе. При загрузке старого сохранения вещи, пересекающие новые стены или проходы, перемещаются на ближайшие доступные места без расходования ресурсов и сброса производственного прогресса; игра сообщает о перестановке.

Магазин, ателье и депо получили тематические стеллажи, прилавки и три дополнительные точки добычи. Номера прежних находок сохранены. Браузерная проверка обходит доступную карту с шагом полметра и проверяет подходы ко всем находкам, входы в пять зданий, мост и запрет установки мебели в проходах.

Карта и движение используют общие расширенные границы; открытия, находки, оставленная добыча и координаты окраин сохраняются.

Состав пополняемых запасов немного меняется между циклами в рамках характерных для места ресурсов. Сгенерированное содержимое и остатки частично разобранных ящиков сохраняются: перезагрузка не меняет находку.

Два дополнительных проекта мастерской: точная оснастка увеличивает выход переработчика до трёх деталей и одного провода, складской приёмник отправляет вручную собранную продукцию на склад без заполнения рюкзака. Оба проекта имеют цветные миниатюры и видимые устройства в убежище. Помощник и ручной сбор используют общий производственный цикл.

В окне склада можно самостоятельно раскрыть итог последней сдачи: материалы и доступные по текущим запасам рецепты. Автоматических целей, наград за заданный маршрут и всплывающего списка обязательных дел нет.


## Обновление 0.8

Бытовая техника, электрощиты, радиоприёмники и двигатели имеют разные модели и время разбора. Набор ключей ускоряет механический разбор вдвое, болторез ускоряет работу с щитами. Подходящие инструменты из набора применяются автоматически; свободный металлолом остаётся обычной быстрой находкой. Техника и ящики имеют коллизии: они исчезают после полного сбора и возвращаются вместе с пополнением запасов. Возвращение откладывается, если игрок стоит на месте контейнера; оставшаяся добыча сохраняет своё количество. Ящик у жилого дома перенесён на крыльцо перед стеной.

Четыре уникальные находки для дома: светильник, кресло, настенные часы и проигрыватель. Они имеют вес, лежат в ячейках рюкзака или склада и расходуются только после успешного размещения. Вещь не появляется повторно после получения. При гибели переносимые находки сохраняются в оставленном рюкзаке. Часы автоматически крепятся к внутренней стороне стены, показывают игровое время и не перекрывают движение по полу.

Посадочная грядка позволяет выбрать травы, овощи или цветы. Семена и вода расходуются при посадке, а не повторно при сборе. Растения визуально проходят стадии роста; урожай собирается вручную, затем требуется новая посадка. Вода и солнечные панели ускоряют рост. Овощи используются в овощной похлёбке, цветы — в букете для дома. Прежние автоматические грядки и производство сохраняют прежнее поведение.

Светильники можно включать и выключать рядом с ними или в обустройстве. Найденный светильник работает независимо от генератора, уличные фонари требуют электричества. Проигрыватель по желанию играет оригинальную тихую мелодию; звук затихает с расстоянием и подчиняется общей настройке звука. Музыка синтезируется локально и не требует загрузки аудиофайлов.

Остановка, оставленный пикник и ремонтный двор получили предметы и три читаемые записи. Их нужно прочитать в мире; затем тексты остаются в дневнике. Задания и автоматические маршруты не добавлены. Всего 48 пополняемых точек ресурсов, четыре уникальные находки и три записи. Старые номера объектов и сохранения совместимы.


## Обновление 0.9

Район расширен тремя местами: жилым двором, складом разобранной техники с пристройкой и рыбацким домиком у тихой заводи. Всего 12 зданий и 64 точки добычи, включая четыре уникальные находки. Запасы соответствуют местам: ткани и овощи во дворе, детали и провод на складе, продукты у воды. В клинике встречаются медицинские материалы: из них и ткани можно изготовить аптечку по альтернативному рецепту. Три новые записи рассказывают о местах и свойствах инструментов без назначения заданий.

Архитектура различается по силуэту и устройству: у домика крутая крыша, навес, сети и вёсла; склад имеет высокий зал, низкую крышу, усиленный фасад и отдельную пристройку; жилой дом — вальмовую крышу, веранду, дымоход, кухню, печь и спальню за перегородкой. Доработаны навесы и детали существующих зданий. Навес становится прозрачным, когда игрок находится под ним; стены, перегородки и дымоходы исчезают вместе с соответствующим разрезом здания.
