# Проверка версии 0.27.0

Изменения развивают существующие ремонтный цех, лодочный сарай затопленной улицы и дальний дом у лесного озера. Новая территория и повторное осушение залов не добавлялись.

## Правила и совместимость

`npm test`: 160 проверок. Новые случаи проверяют однократное получение находок, перенос на склад, установку и загрузку мебели; сохранение списка подготовки; пополнение только дефицита с реальным списанием склада; ограничение веса с учётом мебели и целой техники; повреждённые и старые сохранения; отсутствие расхода при начале очереди и однократный выход завершённых агрегатов.

Идентификаторы прежних 385 узлов сохранены. Новые находки занимают `node-385`–`node-387`. Поле `packingPlan` необязательно в старом сохранении. Очередь разбора не сохраняется и не расходует агрегаты заранее.

## Браузер

Команда проверки:

```sh
npx playwright test tests/browser/rewards.spec.js tests/browser/game.spec.js --grep 'Three finds|Found stations|High quality culls|Fresh story earns'
```

Четыре сценария прошли без ошибок JavaScript и сообщений `console.error`:

- Свободные подходы ко всем новым находкам и отсутствие пересечений с коллайдерами. Проверены 388 узлов и прежний последний узел ремонтного зала. Служебный вход цеха пройден с активными патрулями в обе стороны через здание: без урона, убийств и попадания в стены. Проверены скрывающиеся крыши и конечные координаты трёх новых цветных геометрических пакетов.
- Интерфейс стола: запоминание состава рюкзака, сдача на склад, пополнение и повторное пополнение без дублирования. Интерфейс оснастки: завершение первого агрегата, Escape, сохранность второго, закрытие страницы, загрузка без повторной подстановки начального состояния, завершение остатка. Список и все три установленных предмета сохраняются. Окно также открывается при ширине 390 px.
- Высокое качество: проверены прежние ограничения количества треугольников, отражения, разрешение теней и отсутствие повторного рисования теней.
- Цельный игровой цикл с нуля: обычные начальные ресурсы, 96 переходов, 52 целевых узла добычи, создание снаряжения и домашнего производства, лодка, стоянка и три восстановления. Без выдачи предметов, телепортации или фарма возрождения. Минимальное здоровье 78; три боевых столкновения, 11 циклов помощницы. Этот сценарий повторяет проверку совместимости прежнего развития, а не выдаётся за новую механику.

Сценарии новых станций используют явно заданные запасы и мебель для проверки функций. Проверка маршрутов использует заданные исходные точки соответствующих районов. Только сценарий `Fresh story earns` является непрерывным прохождением с начального состояния. Он знает расположение ресурсов и не подтверждает длительность или интерес человеческого прохождения.

Новые детали окружения — три небольших пакета вершин с цветами. Они не добавляют источников света или постоянных обработчиков обновления. Проверка программного WebGL в облаке не заменяет измерение FPS на реальном встроенном видеоядре.

## Автономный выпуск

`npm run build:standalone` собрал HTML размером 5 663 801 байт и ZIP размером 2 708 868 байт. Проверены CRC, единственная запись `Тихий район.html` и совпадение её содержимого с исходным HTML выпуска. SHA-256 ZIP: `125d88df36966328c6afcbcca8881f6f2e96a9d194fa866a17e8fd12569aef51`.

Производственный HTML проверен в Chromium с отключённой сетью. Облачная политика браузера блокирует навигацию `file://`, поэтому точные байты файла отданы перехватом одного тестового HTTP-адреса без сервера. Это проверка автономного содержимого, а не прямого запуска `file://` в этой среде. Воспроизводимый сценарий — `node scripts/verify-standalone.mjs`.

Результат: 8 встроенных моделей, успешно декодированы все 33 звуковых файла; обращений к внешним адресам и ошибок JavaScript — 0. Через реальные кнопки сохранён список, сдан и пополнен рюкзак, разобраны два агрегата с обычными таймерами. После закрытия страницы сохранены список, мебель и результат разбора (5 деталей); повторного получения нет. При ширине 390 px окно целиком помещается в экран. Отладочный `window.__quietDistrict` отсутствует.
